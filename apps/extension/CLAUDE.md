# apps/extension

Chrome Manifest V3 extension (#445): a popup that saves the current tab to the user's Shelfmark library. Design: Shelf `docs/design-next/shelf/designs/07-extension.html` (block 6b: head and foot rows with `sep` lines, "Goes to … Change", the save shortcut in the foot); earlier `docs/design/screens/Extension.dc.html` and `ExtensionTabs.dc.html` (All tabs, #569); auth decision: ADR 0046; author steps: `docs/SETUP.md` 5.9; store texts and images: `docs/store/extension/`.

## Rules

- **Permissions stay minimal**: `activeTab`, `contextMenus` and host access to `<origin>/api/*`, plus the **optional** `tabs` permission (`optional_permissions`, author-approved for #569): asked at run time, once, by `chrome.permissions.request` on the first switch to All tabs (Chrome's own prompt; declined = stay on This page) and used for `chrome.tabs.query({ currentWindow: true })` (addresses and titles of the window's tabs) and `chrome.tabs.remove` (Close saved tabs). `contextMenus` (author-approved, version 1.3.0) and the module service worker `background.js` give the right-click save (below); neither adds an install warning (Chrome warns for neither `activeTab` nor `contextMenus`; `notifications` would warn "Display notifications", so the result goes on the toolbar badge instead). No `storage`, `scripting`, `notifications`, content scripts or `<all_urls>`; any other permission needs the author's OK (it changes the install warning and the store review). Keep the chrome calls literal (`chrome.tabs.*`, `chrome.permissions.*`, `chrome.contextMenus.*`, `chrome.action.*`, see `browser-tabs.service.ts` and `background/context-menu.ts`). `core/config/config-check.spec.ts` and `scripts/package-extension.mjs` enforce the manifest.
- **Right-click save** (07-extension "Right-click save"): `src/background/` is the service worker, plain TypeScript without Angular, bundled by `scripts/build-worker.mjs` (esbuild) into `dist/apps/extension-worker/<config>/background.js`; the `build-worker` target runs before `build`, which copies the file next to the manifest (`extension:watch` does not rebuild it: run `nx run extension:build-worker:development` after a worker change). On install it creates "Save link to Shelfmark" (links) and "Save page to Shelfmark" (pages), both only for http(s). A click runs the popup's flow without the form (`save-to-shelfmark.ts`): the same routes, origin, timeout and cookie rule (`fetch` with `credentials: 'include'` to `SHELFMARK_ORIGIN` only; the worker never reads the cookie), session check, duplicate check without the #fragment (a saved address is not saved again; the tooltip says where it is), then `POST /api/links` with only the address (and, for a page, the tab title) so the server applies the domain rule, else Unsorted. The result shows on that tab's toolbar button: a ✓ / ! badge (`success` / `danger` token colours) and the words in its tooltip ("Saved to Shopping"), cleared after 6 s; the design's in-page toast would need a content script. Signed out: `chrome.action.openPopup()` opens the popup's sign-in screen (Chrome 127+), else the sign-in page opens in a new tab. Its texts are `chrome.i18n` messages in `public/_locales/*/messages.json` (all seven locales; a spec checks the keys).
- **Data**: only the open tab's URL (without the fragment, for the duplicate check on open) and, on Save, its URL and title plus the folder, tags and note the user picks ever leave the browser. When the user clicks Fill in with AI and AI is on for the account, the page address and title (and the note, with "Include my notes") also go to Shelfmark for AI suggestions, under the existing AI terms; no draft starts on open, and without AI the popup has no AI UI. In All tabs, switching to it (a user action, like opening the popup) checks the listed tabs' addresses, without the #fragment, against the library with the lookup route (the first 24 tabs, the route allows 30 a minute) so "Saved" can show; tab titles stay in the browser. Only the ticked tabs are saved (`POST /api/links/batch`) or sent for AI (Sort with AI: one `POST /api/ai/drafts` per ticked tab, at most 25). Nothing is saved until Save, or until the user picks a right-click item (then that link's or page's address, and the page's tab title, go to the duplicate check and are saved); keep the privacy page and `docs/store/extension/listing.md` in step with this. The popup never reads the session cookie; the browser attaches it (`credentialsInterceptor`, Shelfmark origin only).
- **Two builds**: `shelfmark-origin.const.ts` (production) is swapped for `shelfmark-origin.development.const.ts` by the `development` configuration, and each build copies its own `manifest/<config>/manifest.json`; keep the origin, the host permission and the CSP `connect-src` / `img-src` in step.
- Angular 22 like `apps/web` (load the `angular-v22-rules` skill): standalone, zoneless, signals, `@Service()`, only `libs/ui` components, tokens and `rem`, both themes (no `data-theme`: the popup follows the browser's colour scheme), reduced motion.
- One fixed popup size, 360 x 600 (Chrome's maximum height) (`styles.scss`); every screen uses the global `ext-screen` frame. State and flow live in `PopupStore`; components bind it.
- UI text through Transloco keys in `src/app/core/i18n/en.json`, every key in all seven language files (a spec checks it); plural keys (`one` / `other`, more categories where the language needs them) are built with `pluralKey(base, count, lang)` (`popup/utils/plural-key.ts`); the store name and description, and the worker's menu and tooltip texts, are `public/_locales/*/messages.json`.
- Version: `version` in both manifests; raise it before every store upload (1.3.0: right-click save).

## Commands

```bash
npm run extension:dev        # dist/apps/extension-dev, load unpacked, talks to localhost:4200
npm run extension:watch      # the same, rebuilt on every change (reload the extension card after)
npm run extension:build      # store build in dist/apps/extension
npx nx run extension:build-worker[:development]  # only the background worker (right-click save)
npm run extension:package    # store build + dist/shelfmark-extension-<version>.zip
npx nx test extension [--configuration=coverage]
npx nx run extension:typecheck
npx nx lint extension
npm run extension:icons      # icons from the design-system app icon
```
