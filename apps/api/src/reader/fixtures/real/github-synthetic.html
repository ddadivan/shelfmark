sample-lib

A tiny library for parsing durations such as 1h 30m into milliseconds. It has no dependencies, works in the browser and in Node, and weighs less than one kilobyte once it is minified and compressed with gzip.

Install

npm install sample-lib

Usage

Import the parse function and pass it a string. The result is a number of milliseconds, or null when the text is not a duration. See the API documentation for every option.

import { parse } from 'sample-lib';

parse('1h 30m'); // 5400000
parse('soon'); // null

Units

UnitMeaning
hhours
mminutes
sseconds

Note

Months and years are not supported because their length is not fixed.
