A link with a script URL keeps only its words. Markup written as text, such as <script>alert(1)</script>, stays plain text, and so does an attempt to close the paragraph early with </p><img src=x>.

Control characters such as and are replaced by spaces, so the database never sees a NUL byte and the client never sees a raw escape sequence in the middle of the text.

The rest of this paragraph is ordinary prose so that the page passes the length check: a reader opens it, the server extracts it, and the result is a handful of plain text blocks with no attributes, no URLs and no elements of any kind, ready for the web app to render.
