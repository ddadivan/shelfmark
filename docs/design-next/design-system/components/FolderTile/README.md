# FolderTile
A folder's colour and icon as a small square tile; the only place folder colour appears.

24px (`radius-sm`) in rows, 40px (`radius-md`) in pickers and headers. Glyph `folder-<name>` on tile `folder-<name>-bg`; eight colours chosen by the person; graphite by default. Colour and icon are picked in a Popover.

## In code
`ui-folder-icon`.
