# LinkRow
One link in List and Headlines, inside an L1 panel with hairline dividers.

**List row:** thumb 72×48 (`radius-sm`), title (`body-strong`), favicon + domain, tags, folder, date (`meta`). **Headline row:** 40px, favicon, title (`label`), domain, date. Selected/current: `accent-bg`.
On phones, tags and folder hide; Headlines keep title and date.

## In code
`ui-list-item`, headline row (new).
