# Popover
A small non-modal panel anchored to a control, for choices that take a few seconds: Filter, Move, Remind me, reading settings, Colour and icon.

L2, `radius-md`, up to 320px wide; groups with `meta` headings; changes apply at once; Esc or a click outside closes. Never a dialog for these.

## In code
`ui-popover`, `ui-picker-menu`.
