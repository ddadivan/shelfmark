# AiMark
The spark that marks what AI made and is not yet accepted, in its own indigo.

`ai` colours only the spark and the dashed edge of suggestions; never a fill for text, never the accent. Generated text carries "Written by AI, may be inaccurate" in the spark's tooltip. Accepted suggestions become ordinary content without the mark. AI is a helper inside saving, search and Revisit, never a separate destination.

## In code
`ui-icon name="spark"`, `ui-suggestion`, `ui-ai-line`.
