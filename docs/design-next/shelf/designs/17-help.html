Rules: file links automatically

A rule puts every link from a site into the folder you choose, with tags if you like. Save a link from taylorstitch.com and it lands in Shopping on its own.

3 min readUpdated 20 Nov 2026

Create a rule

  1. Open Settings › Library › Rules and choose Add rule.
  2. Type the site, for example taylorstitch.com. Pages on that site and its subdomains match.
  3. Pick the folder, and tags if you want them. Then Save rule.
New ruleSettings › Library › Rules
taylorstitch.com
Shopping
#clothes
CancelSave rule
Faster: open a link’s ⋯ menu and choose Rule for taylorstitch.com…. The site and its current folder are filled in.

Apply a rule to links you already have

After you save a rule, Shelfmark offers to move the links from that site that are still in Unsorted. Links you already put in a folder stay where they are.

When Shelfmark suggests a rule

If you move three links from the same site into the same folder, Shelfmark asks once whether to do it automatically from now on. Not now hides the offer for that site for 30 days.

Good to know

If a rule’s folder goes to Trash, the rule pauses and new links from that site go to Unsorted until you pick another folder.
