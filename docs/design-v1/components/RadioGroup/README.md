RadioGroup chooses one of a few options with explanations — used in the delete-folder dialog.

**Angular:** `ui-radio-group` — inputs `options: {value, title, description}[]`, `orientation: 'vertical' | 'horizontal'`; Signal Forms binding. Behaviour from Angular Aria radio group (arrow keys move and select).

**Classes:** `sm-radio-group` (`--row`), `sm-radio` (`is-checked`), `sm-radio__dot`, `sm-radio__title`, `sm-radio__desc`.

- The safe option is first and selected by default.
