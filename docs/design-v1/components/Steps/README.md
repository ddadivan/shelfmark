Steps shows progress through the 3-step welcome dialog.

**Angular:** `ui-steps` — inputs `count`, `current`; rendered with `role="img"` and `aria-label="Step N of M"` (through a translation key), so screen readers announce the position once instead of reading three empty dots.

**Classes:** `sm-steps`, `sm-steps__dot` (`is-active` stretches to a sage pill).
