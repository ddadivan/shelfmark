Glass is the frosted surface for layers that float above content for a moment or stay pinned over it.

**Classes:** `sm-glass` (`glass` fill, `glass-line` 1px edge, `shadow-float`, 24px blur with 1.5 saturation). Menus, listboxes and toasts use it automatically.

- Only on: menus, toasts, the phone tab bar, the bulk-action bar, the sign-in card. Never on cards, panels or dialogs' content.
- Reduced motion and unsupported browsers drop the blur; `glass` alone still gives 4.5:1 text.
