StreamingAnswer is an Ask your shelf answer: the user's question as a bubble, the answer streaming in as plain text with numbered citations, the disclaimer line, and the cited links as real link rows. Screens: `AskShelf`, `MobileAiMore`.

**Angular:** `ui-streaming-answer` — inputs `text` (a signal updated as chunks arrive), `citations: { n: number; linkId: string }[]`, `streaming: boolean`; output `citationClicked`. The source rows are the domain `link-row` with its actions (open, side by side, remind me). The question uses `sm-bubble`.

**Classes:** `sm-bubble`, `sm-answer` (15/24, `text`), `sm-cite` (18px rounded number, a button), `sm-stream__caret` (2px `ai` caret, blinking 1 s steps), `sm-ai-line` for the disclaimer "Generated by AI from your links, may be inaccurate." (`ai.disclaimer`).

Behaviour:

- Text is rendered with interpolation only: no HTML, no Markdown. Citations are parsed from structured output (`[n]` markers mapped to link ids the server validated as the user's own), never from free text.
- While streaming: the caret follows the text; "Stop" keeps what arrived; the composer is disabled. Sources and the disclaimer appear when the answer is complete.
- A citation scrolls to and highlights its source row (`accent-bg` for 1.5 s, like a new row in list view); the row opens the link.
- "Not in your links": the answer says so and offers a normal search; it never answers from general knowledge.
- Limit and error use `sm-ai-line` in place of the answer (AiSummary spec); a failed question doesn't count.

Accessibility:

- The answer container is `aria-live="polite"`; screen readers get the text in sentence-sized chunks, not every token (buffer to sentence ends before announcing).
- `sm-cite` buttons are labelled "Source 1"; source rows are a list labelled "Sources from your shelf".
- Reduced motion: no caret blink; text appears in chunks.
