FolderIcon is the coloured tile that stands for a folder in the sidebar, folder tiles, menus and toasts.

**Angular:** `ui-folder-icon` — inputs `icon` (from the Shelfmark set), `colour: 'graphite' | 'sage' | 'ocean' | 'plum' | 'clay' | 'amber' | 'rose' | 'teal'`, `size: 'sm' | 'md' | 'lg' | 'xl'`.

**Classes:** `sm-fic` (28px) with `--sm` 22, `--lg` 40, `--xl` 56, plus `fc-<colour>`, which sets `--fc` / `--fb` from the `folder-<colour>` and `folder-<colour>-bg` tokens.

- Graphite by default; colour is the person's choice. Settings › Appearance › Folder colours off shows every folder in graphite.
- The glyph holds 4.5:1 on its tile in light and dark.
