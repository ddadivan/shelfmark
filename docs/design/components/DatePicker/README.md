DatePicker picks the day for a reminder; presets come first.

**Angular:** `ui-date-picker` — model `date`; presets Later today, Tomorrow, This weekend, Next week above the calendar.

**Classes:** `sm-cal` grid of 7 columns; day buttons `is-muted` (other month), `is-today` (outlined), `is-on` (`primary`).

- Weeks start on Monday; dates and weekday names come from Intl in the interface language.
