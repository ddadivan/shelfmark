Switch turns a single setting on or off at once, with no Save button.

**Angular:** `ui-switch` — model `checked`, input `label` (visually hidden when the row already shows it); Angular Aria `role="switch"`.

**Classes:** `sm-switch` on a `<button role="switch" aria-checked>`; on = `accent` track, the knob slides with `ease-spring`.

- Use for settings that apply immediately (Show notes, Public link). For a choice inside a form that is saved later, use a checkbox.
- 44×26 track; on touch the whole settings row is the hit target.
