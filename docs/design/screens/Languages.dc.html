Layout rules for translations

Plan for strings 40% longer than English. Buttons grow with the text and never truncate; toolbars and saved views wrap to a new line. Sidebar rows and card titles truncate with “…” and show the full text in a tooltip. Fixed-width controls (the language select, segmented controls) are sized for the longest language. Plurals and dates come from Intl, never from string concatenation.
