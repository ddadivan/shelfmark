Everything stays as it is. One new group (outlined here only to show it) between the settings list and “Надіслати відгук”. Both rows open their dialog as a bottom sheet.

Why. Import and export are things you do once in a while, not settings. A menu next to What's new and feedback keeps the sidebar footer to one row and makes import easy to find for someone moving from another tool.

Settings keeps a door. Settings › Privacy and data gets one row «Імпорт і експорт» that opens the same dialogs. The library toolbar «Експорт» (current view) stays.
