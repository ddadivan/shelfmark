One dialog for everyone. Without AI (AI off, Free, demo) the phrase field is not there: the dialog opens on the filter of the feed the user is looking at, each row editable — where (folder picker), type (segmented), tags (tag input, up to 5), search words, sort.

With AI the same rows sit under the phrase (B): AI only fills them; the user can always change any row or skip the phrase and fill them by hand.

Live count and preview in both modes, so an empty view is visible before it is saved ("Знайдено 0 посилань" with the save button still on: an empty view is allowed).

Phone: the same rows in the sheet; the main action alone at the bottom.

AI off or no AI pack. No phrase field and no idea chips; the filter rows of E are the whole dialog. Nothing about the view itself needs AI.

What AI may set. Only what a view already stores: where (all, Unsorted, Favorites, a folder), type, up to 5 existing tags, search words, sort. It never creates tags or folders; an unknown folder or tag becomes search words.

Type of a link (option 1). The AI link job also sets the type (video, article, shopping, other) when the page did not say, so “Videos” stops reading 0 for talks on blogs. The user's own choice in Edit link always wins.
