7 · Поділитися конспектом

A digest can leave Shelfmark two ways: as a public link (built on public collections, ADR 0040) or as copied text. A guest never sees the stored copy, only the person’s points, short quotes and the original link. The link is revocable and not indexed.

What this board covers

The share dialog (off, on, revoke), the public page on desktop and phone, the revoked page, the messenger preview with its OG image, and the copied-text format.

Order of frames

  1. 7a0 dialog off → 7a link on → 7a2 revoke confirm
  2. 7b public page desktop (from 7a, control 3), 7c phone dark
  3. 7f revoked or wrong link
  4. 7d messenger preview + OG image layout
  5. 7e copied text (from 5c, control 5)

Конспект: Чому ми забуваємо прочитане і як це змінити
medium.com — https://medium.com/@olena/why-we-forget

• Без повторення більша частина прочитаного зникає за кілька днів, найбільше в першу добу. (AI)
• «кожне повторення робить криву пологішою»
• Кожне вдале пригадування подовжує проміжок до наступного — у мене це нагадування в календарі.
• Найпростіший розклад: 1, 2, 4, 8, 16 днів. (AI)
• Мій план: перечитувати збережені статті через день, у п’ятницю — переказ.

Зроблено в Shelfmark
Конспект скопійовано5 пунктів, текстом

Plain text that pastes well anywhere: title, site and original link, one «•» line per point, quotes in «», unedited AI points end with «(AI)», a last line «Зроблено в Shelfmark». Also put on the clipboard as simple HTML (list + link) for rich editors. A 3 s toast confirms.

Decisions shown (#539)

  • Public link: own points and short quotes only, never the full copy, always the original link.
  • Revocable; noindex; «Зроблено в Shelfmark» footer.
  • Copied-text format with the original link.
  • Public collections never expose copies.

Open questions for the author

  • Quote limit 300 characters each (shown) — and a cap on the number of quotes?
  • Show the author’s name: off by default (shown)?
  • Mark unedited AI points on the public page and in copied text (shown, «(AI)»), or only in the app?
  • Should a shared digest also appear in a public collection that contains the link?
